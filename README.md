# SS SEO

SEO Intelligence platform for deterministic technical audits, evidence-backed issues, GEO analysis, and fix roadmaps.

## Principles

- **Code measures**: HTTP, HTML, XML, links, metadata, and schema are measured deterministically.
- **Data stores**: crawl snapshots, observations, issues, and audit history are persisted.
- **LLM reasons**: content intent, evidence quality, and prioritization are analyzed only after candidate selection.
- **Human approves**: no production changes are applied automatically.

## Current status

The repository starts with the V0.1 domain contracts and architecture. Runtime services and dependencies will be added in separate, reviewable phases.

## Planned V0.1 modules

- Projects and audits
- Polite, SSRF-safe crawler
- URL normalization
- Technical, indexing, sitemap, robots, canonical, on-page, link, schema, and basic GEO rules
- Evidence-backed issues and fix roadmap
- Recheck and audit history
